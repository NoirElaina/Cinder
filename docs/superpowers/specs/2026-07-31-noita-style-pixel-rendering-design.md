# Noita 风格像素渲染重构设计

## 目标

将现有沙盒世界从“每区块平涂 Sprite”升级为统一的低分辨率像素合成画面。保留模拟、可破坏地形、物质定义和既有目录；使用原创调色板与程序化规则，复刻参考图中的视觉特征，而不复制游戏素材。

## 选择的方案

采用**屏幕级像素帧管线**：按虚拟分辨率采样当前视口的世界格，依次执行材质着色、光照传播、环境遮蔽、空气散射和最终调色，再将结果上传到一张 Point-filter 纹理。

没有采用继续增强 `ChunkView` 的方案，因为区块各自上传的平面 Sprite 无法可靠处理跨区块光照、全屏暗角、低分辨率合成和一致的相机缩放；也没有采用 URP 后处理方案，因为它只能处理已平涂的画面，无法获得逐格材料和邻域信息。

## 架构

- `Runtime/Rendering` 成为唯一的像素画面生产者：`PixelFrame` 保存中间缓冲，Pass 按固定顺序修改缓冲。
- 新的渲染器 MonoBehaviour 从 `WorldController` 获取 `WorldStreamer`、材料数据库、温度和模拟 Tick；它不写入任何模拟数据。
- `ChunkView` 继续保持为项目兼容的区块视图类，但世界正常渲染时禁用其 SpriteRenderer，避免双重绘制。
- 输出纹理以 `FilterMode.Point` 显示在一个正交 SpriteRenderer 上，尺寸与虚拟分辨率匹配；相机仍沿用现有跟随、自由视角和缩放。

## Pass 顺序

1. **采样与材质着色**：逐格读取世界。使用确定性哈希形成矿物斑驳、土壤颗粒、液体深浅和火焰闪烁；根据上下左右邻域为边缘和顶面着色。
2. **局部光传播**：熔岩和火等发光物质向八方向有限半径传播有色光，固体按物质遮蔽系数衰减。
3. **环境遮蔽与空气光**：实心材料的凹角更暗；空格不再显示纯背景，而是只显示少量来自邻近光源的空气散射。
4. **合成与色调映射**：按 Solid/Liquid/Gas/Fire 层混合，保留暗部，压低中间灰度，并为热源增加克制的发光扩散和细微屏幕噪声。

## 材质规则

- 固体：边界深色、凹角阴影、低频团块与高频颗粒共同形成岩层感。
- 液体：顶部亮线、内部深浅分层、受邻接固体影响的暗部；熔岩提供橙红色发光。
- 气体与火：半透明的碎片化体积感，不使用连续模糊云团。
- 可在 `MaterialVisualProps` 与现有材料 SO 中配置，不引入外部图片资源。

## 失败隔离与验证

- 窗口外、未加载或空格统一返回安全的背景采样，渲染绝不请求加载区块。
- 纹理与缓冲在分辨率改变时一次性重建，销毁时释放；每帧不分配托管数组。
- 增加编辑器测试：邻域边界、光照遮挡、点采样输出和确定性着色。
- 编译后在 Unity Play Mode 验证：地形、液体、火/熔岩、F2 温度图、重置和相机缩放均继续工作。
